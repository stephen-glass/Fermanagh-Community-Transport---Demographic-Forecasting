# Fermanagh Community Transport Population Modelling

## Overview

This project developed a population projection model for **Fermanagh Community Transport (FCT)** to investigate how demographic change could affect the population of Fermanagh over the coming years.

Starting from a **2021 population of 63,585**, the model projected population changes across four age groups by incorporating age-specific **death rates and migration rates**.

## Methodology

The population was divided into four age groups:

* 0–14
* 15–39
* 40–64
* 65+

For each age group, the model incorporated estimated population proportions, mortality rates and migration rates to project future population levels.

The model was also used to investigate the uncertainty associated with the projections, including the potential use of **Central Limit Theorem-based confidence intervals** to quantify variation in the estimated population.

## Key Findings

The projections demonstrate how differences in mortality and migration between age groups can lead to substantial changes in the demographic structure of Fermanagh over time.

The analysis provides a quantitative framework that can help FCT understand potential future changes in population size and age composition when considering transport demand and service requirements.
